# nimrod project

nimrod project へようこそ。金融、生産性、日常のユーティリティに特化したモバイルアプリケーションを開発しています。

---

## アプリ一覧

### 住宅ローン/ローン計算機

毎月の返済額、総利息、ローンの比較を簡単に計算できます。

- 元金・利息の内訳付き月額返済額の計算
- 総利息・総返済額の計算
- ローン比較ツール
- **iOS** と **Android** で利用可能

### Accumulate+（積立シミュレーター）

複利計算機能を備えた積立投資プランニングアプリ。投資の長期成長を視覚化できます。

- 複利シミュレーション
- 老後の引き出しシミュレーション
- 年齢・暦年付きの詳細な年次予測
- **iOS** と **Android** で利用可能

### ネットワーク速度テスト

インターネット接続速度を簡単にテスト。最適なサーバーを自動検出し、速度とPing遅延を測定します。

- ダウンロード/アップロード速度測定
- Ping遅延テスト
- チャートでの視覚的表示
- ランキングと平均値の比較
- **Android** で利用可能
